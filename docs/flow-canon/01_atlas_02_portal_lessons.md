### P-01 역할별 초대
- [ ] **구현 완료** — 역할별 초대가 발급·전달·본인 확인·수락을 거쳐 계정·관계가 활성 상태가 됨
- **주 전환:** 등록 활성화 → 초대 대상과 역할 확인 → 학생·보호자·납부자별 초대 발급 → 전달 → 본인 확인 → 수락 → 계정·관계 활성

  - [ ] 한 사람이 여러 역할: 한 계정에 역할을 각각 연결.

  - [ ] 새 초대 발급: 이전 초대 즉시 무효.
  - [ ] 발송 실패: 같은 초대를 다시 전달하며 불필요하게 새 초대를 만들지 않는다.
  - [ ] 기존 확인 계정이 있는 대상: 새 계정을 만들지 않고 본인 확인 후 새 역할·관계만 연결.
  - [ ] 초대 수락 중 계정·역할·학생관계 일부 연결 실패: 수락 전체를 완료로 표시하지 않음 → 생성된 반쪽 연결 회수 → 원 초대 복구 또는 새 초대 → 전체 재시도.
  - [ ] 한 번 완료된 초대 재사용: 기존 계정·역할 결과로 수렴하고 새 관계를 중복 생성하지 않는다.

### P-02 이용자 로그인·세션·복구

### P-07 계정 탈퇴

  - [ ] 법정 보존 대상: 접근은 닫되 데이터는 분리 보존.
  - [ ] 재가입: 파기 전이면 확인 후 기존 주체에 새 초대, 파기 후면 신규 주체로 시작.

### P-08 운영자 로그인·2단계 인증
- [ ] **구현 완료** — 2단계 인증을 통과한 활성 운영자만 운영자 영역에 접근함
- **주 전환:** 운영자 로그인 → 활성 운영자 본인 확인 → 2단계 인증 상태 확인 → 2단계 인증 상태 분기: 미등록 → 인증수단 연결 → 확인코드 검증 → 등록 완료 → 운영자 접근 / 2단계 인증 상태 분기: 등록됨 → 확인코드 요청 → 성공 → 운영자 접근 / 2단계 인증 상태 분기: 코드 오류·만료 → 제한된 재시도 → 성공 또는 접근 종료 / 2단계 인증 상태 분기: 인증수단 분실 → 승인된 운영자 복구절차 → 기존 인증수단·세션 회수 → 새 인증수단 등록
- **예외·복구·종료:**
  - [ ] 2단계 인증 완료 전 비노출: 운영자 영역은 2단계 인증 완료 전 비노출.
  - [ ] 인증수단 해제: 최근 강화 인증 확인 → 해제 승인 → 모든 운영자 세션 회수 → 새 인증수단 등록 전 운영자 접근 차단.
  - [ ] 반복 실패·의심 접근: 새 인증 시도 제한 → 보안사고 검토 → 안전 확인 후 복구 또는 차단 유지.
  - [ ] 일반 이용자 복구 경로 우회 금지: 일반 이용자 로그인 복구로 운영자 2단계 인증을 우회하지 않는다.
