## 슬라이드 5 — 공개 운영·상담신청·상담

핵심 메시지: 상담을 열기 전에 운영 안전성과 공개 사실성을 닫고, 접수 후 중복·정원·연락 결과를 운영자가 판정한다. `O-01–O-05 · C-01–C-07`

- [ ] 운영 개통: 강화 인증 → 정책·외부 제공자 → 백업·복원 → 공개 검토 → 운영자 승인 → 상담 개시
- [ ] 상담: 신청서·동의 → 접수번호 → 중복·기존관계 → 검토·첫 연락 → 상담 → 시범·정규·대기·종결
- [ ] 접수번호 분실: 본인 확인 → 번호 복구 → 제한된 상태 안내
- [ ] 대기: 자리 발생 → 순서·적합성 재확인 → 기간 있는 한 명 제안
- [ ] 철회·종결: 열린 폼 닫기 → 정산 → 종료 안내 → 보존기한

## 슬라이드 6 — 시범수업·정규수업 등록

핵심 메시지: 시범은 일정·결제·출결·결과까지 닫고, 정규 등록은 네 조건이 모두 확정된 뒤 활성화한다. `T-01–T-04 · R-01–R-06`

- [ ] 시범: 신청폼 → 운영자 검토 → 일정 합의 → 유료면 결제 → 수업·진단 → 정규·대기·종결
- [ ] 정규 등록: 정규 신청폼 → 관계 → 계약 → 결제 → 일정·정원 → 활성·포털 초대
- [ ] 네 게이트: 관계 · 계약 · 결제 · 일정이 모두 완료돼야 활성
- [ ] 시범 노쇼: 주체·시각·귀책 → 재예약·비용·종결 판정
- [ ] 활성 전 포기: 열린 제안 닫기 → 결제분 환불 → 보존

## 슬라이드 7 — 계정·초대·역할별 포털 순환

## 슬라이드 8 — 수업 묶음·일정·출결·수업기록

핵심 메시지: 계약 조건으로 반복 회차를 만들고, 실제 수업 사건으로 출결·기록·잔액·보강·보고서를 함께 갱신한다. `L-01–L-10`

- [ ] 반복 일정: 계약·묶음 → 회차 후보 → 충돌 확인 → 정상 확정 / 충돌 재협의 → 전체 안내
- [ ] 한 회차: 수업 준비 → 출결 → 수업 → 기록·진도·과제 → 운영자 승인 → 게시·잔액
- [ ] 변경·보강: 주체·시각·귀책·합의 → 정책 판정
- [ ] 기존 일정: 모의 검토 → 승인본 재대조 → 반영·대사

## 슬라이드 9 — 과제·제출·피드백·질문·학습파일

핵심 메시지: 과제와 질문은 원 수업에 연결되고, 업로드 파일은 비공개 검사에서 안전 확인된 항목만 사용한다. `H-01–H-07`

- [ ] 과제 순환: 과제 초안 → 승인·배부 → 학생 제출 → 검사·확정 → 채점·피드백 → 재제출·종료
- [ ] 질문·파일: 원 기록 질문 → 답변 승인 · 파일 권한 → 격리·안전 검사 → 열람 · 기존 이력 반영·대사
- [ ] 재제출: 기존 제출과 새 제출을 연결하고 최신 승인본 유지
- [ ] 파일 위험: 격리 → 거절·안전 변환·재제출
- [ ] 과제 종료: 대상별 상태 확인 → 보관·취소·종료

핵심 메시지: 공개 전 동의·사실·증빙·출처를 확인하고, 철회·만료 시 공개 경로를 회수한다. `S-01–S-07`

- [ ] 입시정보·분석: 공식 출처 → 수집·정규화 → 기존 일정 비교 → 운영자 승인 → 게시·내보내기 → 주간 보고

핵심 메시지: 접근 회수·법정 보존·실제 삭제는 서로 다르며, 자동파기는 운영자 승인과 잔존 확인 뒤 완료된다. `D-01–D-09`

- [ ] 자동파기: 기한 계산 → hold·미정산 분리 → 파기 후보 → 운영자 승인 → 주·외부·백업 삭제 → 잔존 0
- [ ] 파기 실패: 미완료 → 재시도·운영업무 → 잔존 확인
- [ ] 복원: 서비스 연결 전 과거 파기 목록 재적용
- [ ] 외부 AI: 목적·정보·제공자 안내 → 동의·철회·수동 대체
- [ ] 접근 회수 · 법정 보존 · 실제 삭제는 서로 다른 개념으로 구분

- [ ] 권한 변경: 세션·초대·링크 회수
- [ ] 금전 불일치: 원 승인 대조·조정·재대사
