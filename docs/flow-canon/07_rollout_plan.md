# 반영 계획 — ONE-SHOT 전 범위 구축 로드맵

> 정본 3문서(SHA-256 03BC551C…8301) 선언: **FLOW-ONLY / ONE-SHOT BUILD · 전 범위 일괄 구축**.
> 따라서 아래 마일스톤은 "배포를 쪼개는 단위"가 아니라 **한 번의 구축 안에서 지켜야 할 의존성 순서**다. 어떤 도메인도 범위에서 탈락하지 않는다.
> 각 마일스톤의 완료 판정 = 대응 플로우의 「구현 완료」 체크(01_atlas_01~05) + 관련 검수 시나리오(03_scenarios_133) 통과.

## 원칙

1. **정본 우선**: 현행 코드(기획 7-x·AI 리포트 기획안 계열)와 충돌하는 17건(06_gap_summary)은 정본 구조로 이행한다. 기존 데이터는 보존·이관하되 구조는 문서를 따른다.
2. **불변식 선행**: 02_invariants의 공통 수렴 규칙 10개는 특정 마일스톤이 아니라 **모든 마일스톤의 수용 조건**이다. 특히 「감사 연결 실패 시 전환 미확정」·「업무 성공과 전달 성공 분리」·「승인된 사실은 덮어쓰지 않는다(조정 이력)」는 M0에서 기반을 깔지 않으면 이후 전 도메인에서 재작업이 난다.
3. **화면·필드·DB·API 상세 설계는 각 마일스톤 착수 시점에** 해당 플로우 범위만큼 수행한다(문서 경계 준수 — 이 계획은 흐름 순서만 고정).
4. **고정 순서 준수**: 상담→시범/정규→포털→수업·학습→결제→종료→파기. 구현 중 임의 생략 금지(§17).
