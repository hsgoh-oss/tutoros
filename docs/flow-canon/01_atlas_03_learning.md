### H-02 과제 제출·재제출
- [x] **구현 완료** — 학생이 배부 과제를 확인하고 파일·내용 검사를 거쳐 제출 완료 후 운영자 검토 업무로 넘어가는 흐름이 동작한다.
- **주 전환:** 학생이 배부 과제 확인 → 제출 시작 → 파일·내용 검사 → 안전한 항목 확정 → 제출 완료 → 운영자 검토 업무
- **예외·복구·종료:**
  - [ ] 일부 업로드 실패: 성공 항목 유지 → 실패 항목만 다시 제출.
  - [ ] 안전하지 않은 파일: 격리 → 거부 안내 → 안전본 재제출.
  - [ ] 마감 후 제출: 차단하지 않고 지연 사실과 실제 시각을 연결.
  - [x] 재제출: 이전 제출 보존 → 새 제출본을 최신 검토 대상으로 연결.
  - [ ] 제출 철회: 검토 전이면 철회, 검토 후면 운영자 정정 흐름.

### H-03 채점·피드백·재제출 순환

- **주 전환:** 제출 확인 → 운영자 검토·채점 → 피드백 초안 → 공개 대상 확인 → 승인·게시

  - [ ] 미승인 피드백: 미승인 피드백은 알림·포털 비노출.

  - [ ] 철회 피드백 재게시: 철회한 피드백을 그대로 재게시하지 않고 새 본으로 처리.

### H-04 학생 질의응답
- [ ] **구현 완료** — 학생 질문 접수부터 원 기록 확인, 답변 초안, 운영자 승인·게시, 학생 확인까지 동작한다.
- **주 전환:** 학생이 수업·과제·문항·피드백 원본에서 질문 → 질문 접수 → 운영자 답변 업무 → 원 기록 확인 → 답변 초안 → 운영자 승인·게시 → 학생 확인

  - [ ] 운영자 추가 과제 필요: 과제 흐름으로 연결.
  - [ ] AI 답변 초안: 승인 전 비노출.
  - [ ] 다른 학생·무관계 보호자: 질문 존재 자체를 노출하지 않는다.

### H-07 과제 종료·대상 취소·보관

- **주 전환:** 게시 과제 → 대상별 제출·검토·재제출 상태 확인 → 운영자 종료 판단
- **예외·복구·종료:**
