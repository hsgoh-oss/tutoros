## Appendix D. 개발자 전달 규칙

- [ ] 확인 필요, 대기, 처리 중 상태에는 반드시 운영자 업무 또는 자동 재확인이 연결돼야 한다.

- [ ] 기능·화면·데이터 모델은 이 문서 밖에서 정하되 여기의 상태 의미와 분기를 바꾸지 않는다.
