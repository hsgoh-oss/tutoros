# 성인 본인 연락·납부

학생 등록·수정의 수강생 구분에서 `성인 · 본인 연락 및 납부`를 선택한다.
본인 연락처와 연락처 수집 동의 확인이 필요하며 보호자 연락처는 입력받거나 저장하지 않는다.
기존 학생과 CSV 등록은 미성년자·보호자 연락 방식으로 유지된다. 상담에서 전환한 학생은 상세에서 구분을 설정한다.

청구 안내, 결제선생 청구서, 과제 배부, 보강, 등록 완료·종료 안내는 성인의 본인 번호로 발송한다.
보호자용 리포트는 보호자 전용이며 성인에게 본인용 리포트를 게시한다.

## 포털

관리자가 본인 번호로 학생 초대를 보내고 본인이 수락하면 기본 학생 탭과 납부자 탭을 함께 사용할 수 있다.
성인 설정 자체가 로그인 수단은 아니다. 활성 학생 관계와 등록된 본인 번호 일치가 모두 필요하다.
보호자 역할은 자동 생성하지 않는다. 납부자 화면과 학생 화면의 데이터 조회는 계속 분리한다.

본인 납부 권한은 매 요청 학생 관계에서 파생한다. 학생 관계 회수, 성인 설정 해제, 본인 번호 변경,
등록 종료 시 파생 권한도 닫힌다. 별도 납부자 관계가 있으면 그 상태를 우선하며 초대 대기·회수된
납부 권한을 자동으로 되살리지 않는다. 본인 납부만 차단하려면 해당 번호의 별도 납부자 관계를 회수한다.

## 적용·검증

앱 배포 전에 `00031_adult_students.sql`을 적용하고 `automation` Edge Function도 함께 배포한다. 기존 학생 구분은 바꾸지 않는다.
개인정보 파기 시에는 기존 파기 함수가 연락처를 지울 수 있도록 연락처 제약에서 파기 완료 행을 제외한다.

`pnpm verify:adult-students`는 외부 발송 없이 등록·수정, 연락처 수신자, 본인 납부 권한과 회수 조건을 검증한다.
